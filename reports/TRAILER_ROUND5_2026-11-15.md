# Раунд 5 — прицепы, грязные T5070 и проверка прежних классов

15 ноября 2026 года. Новые файлы находятся на D. GitHub в этом раунде не обновлялся.

## Изменение распознавания прицепов

Добавлено подтверждение прицепа двумя способами:

1. Дополнительный проход детектора с явным классом «прицеп». Его область должна совпадать с предложенной областью машины, а оценка прицепа — превышать оценку самоходной техники с запасом. В многомашинной сцене требуется положительное подтверждение другой машины.
2. Сравнение изображения области с вручную размеченными эталонами прицепов и машин в признаках DINOv2/ConvNeXt. Разность ближайших косинусных сходств должна превышать порог, выбранный по групповым вневыборочным предсказаниям.

Только совпадение этих свидетельств исключает область из машин. Порог разности сходств — **0,10979**, поддержка — **11 обучающих групп**, без ошибочного исключения машины в принятой OOF-области. Это не вероятность и не доказательство точности на любых новых источниках. Все варианты одного исходного фото/машины остаются в одной группе.

Старые основной и фрагментный проверяющие классификаторы сохранены. Точное семейство после нового исключения прицепа удерживается для проверки человеком: этот путь ещё не получил независимой калибровки. Это предотвращает превращение прежнего ошибочного кандидата New Holland в уверенный ответ после удаления лишней области.

Первый вариант с одним текстовым признаком ошибочно отбрасывал настоящий комбайн и второй трактор; он отклонён. Отдельные линейные классификаторы проверены, но не дали достаточного подтверждения проблемного прицепа при откалиброванном пороге. Их пороги ради контрольного примера не снижались. В рабочий вариант включено сопоставление с эталонами вместе с текстовым подтверждением.

## Что стало обучением, а что осталось контролем

Известное дождевое фото New Holland с зелёным прицепом `weather4/w4_021` вручную размечено: это один трактор и один прицеп, а не две самоходные машины. Область прицепа использована как **обучающая обратная связь**. Снимок перенесён из `round4_test` в `round4_feedback_regression`. Улучшение на нём — исправление известной ошибки, не независимый результат.

Прежние 158 фото не использовались для обучения. Дополнительные прежние наборы 12 зимних, 9 дополнительных и 3 T5000 также сохранены вне обучения. Для новой проверки оставлены два прицепа из двух других источников и отдельный T5060. Чистота групп проверена; два новых прицепа не включены в эталоны.

Пять новых фото прицепов вручную проверены; на двух исходных снимках с трактором обучающая область ограничена самим прицепом. Три источника использованы для обучения, два — для контроля. Реальные фрагменты этих снимков дополняют обучение; они не считаются новыми независимыми фотографиями.

## Повторное обучение семейства

Обучены общая голова семейства, специалист T5000 и совместный вариант. Все три отклонены по проверкам прежних классов. Рабочие веса распознавания семейства, специалиста МТЗ и состояния оставлены прежними.

| Вариант | Верные кандидаты семейства | Верные ответы | Ошибочные ответы |

| Прежний рабочий комплект | 142 | 103 | 3 |
| Новая общая голова | 142 | 102 | 2 |
| Новый специалист T5000 | 142 | 102 | 3 |
| Обе новые головы | 142 | 101 | 2 |

Общая голова теряла верные ответы на CLAAS AXION 800 и МТЗ-1221, специалист T5000 — один верный ответ T5000. У общей головы также стало 2 верных кандидата из 3 на прежнем новом контроле T5000 вместо 3. Уменьшение ошибок ценой таких потерь не принято как улучшение без регрессии.

На тех же признаках с сохранённым OCR у оставленного рабочего комплекта по-прежнему **103 верных и 2 ошибочных ответа** на 158 фото; зимой — **7 верных кандидатов из 12, 4 верных и 3 ошибочных ответа**. Нового повышения точности семейства в этом раунде не заявляется.

## Проверка распознавания объектов

Исходный аудит охватил 183 прежние контрольные записи, включая впоследствии переведённый в обратную связь дождевой кадр. Текстовая проверка предлагала исключить области на девяти фотографиях. Они просмотрены вручную: среди них были и настоящие машины, поэтому одного текстового признака недостаточно.

Эталонная проверка не дала ни одного предложения исключить основную машину на сохранённых признаках прежних 158 + 12 + 9 + 3 и нового T5060. На отдельном контроле из 30 реальных фрагментов машин ложных исключений не было. Два новых независимых прицепа распознаны как прицепное оборудование; прежняя проверка также отсеивала их, поэтому улучшение на этих двух кадрах не заявляется.

## Ограничения

Не все прицепы и орудия надёжно отделяются от машины. В старом контроле остаются ложные области красного прицепа, цистерны и отвала. Эти случаи не переименованы в правильные и не использовались как новые обучающие примеры из прежних 158 фото. Нужны отдельные обучающие фото цистерн, высокобортных прицепов, погрузчиков и частично скрытых комбайнов из новых источников.

Дождь и мокрая поверхность пока не включены как надёжно подтверждаемые состояния. Голова грязи в этом раунде не переобучалась. Точные модели автоматически не подтверждаются. Сам факт исправления обученного примера не доказывает устойчивость к новым дождевым сценам.

## Воспроизведение

Рабочее окружение — `D:/machinery-vision/envs/tractor/Scripts/python.exe`, каталог — `D:/machinery-vision/project`. TEMP, TMP, TORCH_HOME, MPLCONFIGDIR и YOLO_CONFIG_DIR должны указывать на D; используются локальные офлайн-веса.

```powershell
python -B -m scripts.prepare_trailer_round5
python -B -m scripts.build_trailer_round5_features
python -B -m scripts.train_trailer_round5_family
python -B -m scripts.prepare_trailer_round5_feedback
python -B -m scripts.audit_trailer_round5
python -B -m scripts.train_trailer_round5_fixed_verifier
python -B -m scripts.train_trailer_round5_references
python -B -m scripts.eval_trailer_round5_main
python -B -m scripts.validate_trailer_round5
python -B -m pytest tests -q -p no:cacheprovider
```

Аудит первоначальных семантических предложений сохранён; его строки не означают окончательное исключение машины. Для запуска с нуля также нужен сохранённый `semantic_diagnosis.json` с предложением области известного прицепа или повторный запуск `scripts.diagnose_trailer_round5`. Выпуск выполняется отдельным скриптом после проверок, семейство и состояние автоматически не заменяются.
