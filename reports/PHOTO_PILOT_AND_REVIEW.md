# Новая партия фото МТЗ и ручная проверка

## Сбор и обучение

Из 14 найденных страниц Wikimedia Commons получены 6 фотографий с указанием
автора и лицензии. Повторные ответы HTTP 429 ограничили сбор. Остальные ссылки
и статусы сохранены в `output/photo_pilot/collection_sources.json`.
Из шести фото три МТЗ‑1221 добавлены в обучение, два остались в проверке
(МТЗ‑82 и МТЗ‑1221), один МТЗ‑1221 отложен из-за близости pHash 8 к старому
кадру. Сверены исходные, синтетические и ранее использованные контрольные
данные, включая зеркальные версии. pHash проверяет сходство изображений,
а разные ракурсы одной машины требуют проверки происхождения.

Во всех прогонах использовались замороженный DINOv2 Small и новая
логистическая голова, вход 224 px с сохранением пропорций. Базовый вариант
обучен на тех же 89 исторических кадрах; два остальных получили ещё три фото.
Тест общий: 7 кадров из 5 групп, включая три ракурса одной машины МТЗ‑1221.3.
Пять кадров уже использовались для предыдущей диагностики; два новых
в тесте не участвовали в обучении ни одного варианта.

| Вариант | Верные кадры | Группы без ошибок |
| --- | ---: | ---: |
| Базовый | 6/7 | 4/5 |
| Добавлены три снимка | 6/7 | 4/5 |
| Добавлены три снимка, вес каждого ×3 | 7/7 | 5/5 |

Разница — один задний ракурс. При обычном добавлении его оценка сместилась
к границе (0,51 за МТЗ‑82 против прежних 0,58), а повышенный вес изменил ответ.
Тест мал и повторно использован для сравнения. Следующий набор стоит пополнить
другими экземплярами МТЗ‑1221, особенно задними ракурсами, и МТЗ‑82 со схожей
окраской, чтобы проверка не сводилась к цвету. Веб-панель показывает обе модели
загрязнения. Результаты по загрязнению описаны в [предыдущей проверке](EXTERNAL_VALIDATION.md).

Скрипты из корня Git:

```powershell
python -m scripts.collect_mtz_pilot --output output/photo_pilot
python -m scripts.train_mtz_photo_pilot --collection output/photo_pilot --output output/photo_pilot
```

Первый скрипт скачивает картинки и метаданные для просмотра. Обучение использует
отдельный список проверенных фотографий `downloaded_metadata.json` со
SHA‑256 и фиксированными ролями. Новые файлы ждут визуального отбора и
сверки с контрольными данными.

## Локальная панель оператора

Из корня Git с текущим окружением:

```powershell
..\envs\tractor\Scripts\python.exe -m scripts.review_web_app
```

Откройте <http://127.0.0.1:7861/>. Можно изменить порт параметром `--port`.
Панель принимает JPEG, PNG и WebP, показывает семейство, три варианта
определения МТЗ (если семейство распознано как МТЗ), v3 и кандидата по грязи.
Метки модели, грязи и поверхности сохраняются вместе с фото локально, по
SHA‑256, в `output/operator_review/reviews.sqlite3`. Повторное сохранение
того же файла обновляет его оценку. Кнопка «Скачать CSV» выгружает метки.
Сохранённые оценки остаются в очереди для последующего отбора.
