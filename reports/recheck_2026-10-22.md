# Пересчёт метрик, 2026-10-22

Для этой проверки использовался исходный probe из 19 фото. Два кадра затем
исключили по совпадению SHA-256 с `train`. Результат на 17 фото есть
в [отчёте v3 от 14 ноября](error_analysis_v3_probe17/sweep.json).

Метрики пересчитаны командами на данных и весах исходного проекта (чтение, без
записи в исходный каталог). Окружение: Python 3.11.15, PyTorch 2.14.1 (CPU),
PyTorch Lightning 2.6.6; чекпоинты обучены на Lightning 2.6.5. Результаты на CPU
могут отличаться от GPU-запусков в пределах численного шума.

Обозначения: v1 — `multi-task-best-epoch=13-val_model_acc=1.000.ckpt`,
v2 — `multi_task_best.ckpt`, v3 — `multi_task_best_v3.ckpt`
(см. [weights_inventory.md](weights_inventory.md)). Наборы: `real_dirty_val` — 28 фото,
`real_clean_probe` — 19, `data/dirty_clean/test` — 102 clean + 206 dirty,
`data/dirty_clean/val` — 330.

## Команды

```powershell
# свип порога и отчёт по промахам (для v2 и v3)
python -m scripts.error_analysis_state --checkpoint <ckpt> --synthetic-dir data/dirty_clean/test `
    --real-dirty-dir data/real_dirty_val --real-clean-dir data/real_clean_probe --out-dir <dir> --sweep
python -m scripts.error_analysis_state --checkpoint <ckpt> ... --out-dir <dir>

# accuracy на val (v1, v2, v3)
python -m src.training.multi_task_evaluate --data-dir data/dirty_clean --checkpoint <ckpt>
```

Результаты v2: [error_analysis_v2_cleaned/](error_analysis_v2_cleaned/). Для v3 повторный
запуск дал `sweep.json` и `sources` из `report.json`, совпадающие по значениям с
[error_analysis_v3/](error_analysis_v3/).
