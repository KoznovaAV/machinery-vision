102 чистых фото из синтетического `test` и 17 реальных чистых фото.

| Файл | Что |

| [MODEL_CARD.md](MODEL_CARD.md) | назначение, архитектура, обучение, метрики, решение по состоянию, версия чекпоинта, ограничения |

| `error_analysis_baseline/`, `error_analysis_v2/`, `error_analysis_v2_cleaned/`, `error_analysis_v3/` | `report.json` — промахи головы состояния по источникам и классам, `sweep.json` — свип порога `p(dirty)` |

Получены `scripts/error_analysis_state.py` (`--sweep` для свипа). Поле
`checkpoint` в каждом JSON указывает чекпоинт разбора. Изображения промахов
(`clean_as_dirty/`, `dirty_as_clean/`) в репозиторий не включены; воспроизводятся
тем же скриптом.

Наборы: real dirty = `data/real_dirty_val`, synthetic clean = чистые из
`data/dirty_clean`, probe = `data/real_clean_probe`. В исходных отчётах
`baseline` и `v2` было 32 / 103 / 23 фото. В `v2_cleaned` и `v3` было
28 / 102 / 19 фото после исключения снега и мусорных кадров. Для сравнения
v2 и v3 на одной выборке см. [пересчёт от 22 октября](recheck_2026-10-22.md).
