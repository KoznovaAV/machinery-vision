# Обучение кандидата

Подготовьте окружение и веса по README, поместите актуальный комплект `datasets/` в корень проекта. Сначала `python -m scripts.audit_data`.

```bash
python -m scripts.train --task mtz
python -m scripts.train --task families
python -m scripts.train --task conditions
python -m scripts.train --task regions
```

Выбирайте нужную задачу отдельно. Результат — новая папка `runs/training/<задача>-<время>`; другой новый путь внутри проекта можно задать `--output runs/my-candidate`. Рабочие артефакты не заменяются.

- `mtz`: отдельное обновление специалиста МТЗ без изменения головы семейств. Сравнение по каждому классу и срезу; кандидат требует полного прогона сцен.
- `families`: сравнение общей головы/специалиста T5000 с текущими границами по всем контрольным классам и срезам.
- `conditions`: отдельные головы грязи/снега/дождя/влажности. Недостаточная поддержка групп ведёт к пропуску обучения или отказам.
- `regions`: эталонная проверка области и линейное подтверждение прицепов/цистерн; сохранённые исходные головы областей и фрагментов не заменяются.

Обучение использует взвешивание по группам, групповые OOF-предсказания и калибровку. Для смешанных областей калибровка учитывает худший принятый ответ в каждой группе. Повторное обучение не означает улучшение качества: сравнивайте ошибочные ответы, верные принятые ответы и отказы отдельно.

Базовые результаты на сохранённых признаках воспроизводятся командой `python -m scripts.benchmark`: без OCR, детектора и дополнительных отказов веб-конвейера. Выходные JSON содержат построчные решения и хеши входных данных.

Численные отчёты и проверки допуска лежат рядом с кандидатом. Условия сравнивайте на тех же размеченных срезах; оценивать нужно каждый класс отдельно. Отдельно проверьте новый независимый контроль и полные сцены. Команда `python -m scripts.evaluate` проверяет текущий установленный комплект на 20 диагностических сценах; сама по себе не оценивает кандидата до его отдельного подключения.

Установка кандидата — отдельная работа ответственного инженера: проверки, согласованная версия кода/справочника/весов/порогов, обновление манифеста SHA, полный прогон и возможность отката. Автоматическая установка не предусмотрена. Не запускайте обучение на собственных прогнозах как на достоверных метках.
