# Передача разработчику

Главная инструкция запуска — README. Для автономного Windows x64/CPU комплект содержит `project/`, переносимый Python, локальные wheels, файл зависимостей, скрипты запуска и манифест SHA. В `project/` есть `datasets/` и `weights/`; в новом клоне GitHub их нет.

Распаковать в отдельную папку на любом диске. Из корня комплекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Check.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Web.ps1
```

Пути вычисляются относительно папки комплекта. Новое `.venv` создаётся внутри `project/`; старое виртуальное окружение не копируется. Для Linux/macOS установить Python 3.11 и зависимости по README: Windows wheels/переносимый Python для них не подходят.

Перед редактированием проверьте `Verify-Files.ps1`, после установки — `python -m scripts.check_release`. Первый проверяет весь переданный набор, второй — код и активные артефакты. Проверка SHA не является измерением точности. После собственной работы полный манифест первоначального архива закономерно перестаёт соответствовать изменённым файлам.

Рабочий комплект выбирается единственным `artifacts/mvp/current_release.json`. Не смешивайте головы, справочник, пороги и эталоны разных выпусков. Веса области переднего моста входят в комплект артефактов. Для отката сохранять вместе Git-коммит и весь комплект весов/метаданных.

Нужен ответственный за предметную разметку и инженер за выпуск. Исправления пользователей сначала попадают в проверяемую очередь, затем — в групповое обучение кандидата и сравнение. Без сопровождающего оставить рабочую версию замороженной. Текущее приложение от распознавания не обучается.

Задачи, ограничения и результаты проверки: MODEL_CARD.md. Лицензии Python и зависимостей входят в комплект.

## Временный публичный доступ

После установки весов запустите отдельный экземпляр приложения из корня проекта:

```bash
python -m scripts.web --public-demo --port 7866
```

В другом терминале, из той же папки, откройте HTTPS-туннель (нужен OpenSSH):

```bash
ssh -T -o UserKnownHostsFile=.cache/demo_known_hosts -o IdentityFile=none -o IdentitiesOnly=yes -o ServerAliveInterval=30 -R 80:127.0.0.1:7866 nokey@localhost.run
```

При первом соединении проверьте и подтвердите ключ сервера. Публичный адрес появится в терминале SSH. Обновите ссылку в README, если адрес изменился. Оба терминала должны оставаться работающими; `Ctrl+C` останавливает соответствующий процесс. Бесплатные домены меняются, скорость ограничена: [условия localhost.run](https://localhost.run/docs/forever-free).

Наружу направляется только порт публичного экземпляра. Обычный интерфейс с локальной историей не публикуйте. Режим `--public-demo` использует отдельную папку `runs/public-demo/`, убирает метаданные загруженного изображения и закрывает JSON/HTML артефакты, OpenAPI и документацию API. Доступны только изображения результата с непредсказуемыми идентификаторами и сроком 20 минут. Файлы удаляются при работающем приложении; после аварийной остановки очистка продолжится при следующем запуске публичного режима. Не запускайте этот режим с несколькими worker-процессами: ограничения очереди рассчитаны на один процесс.

Это демо без аккаунтов и гарантии доступности. Для постоянного размещения нужны отдельный сервер, контроль доступа, лимиты нагрузки и политика хранения загрузок. Модель не дообучается на загружаемых фото.
