# Передача разработчику

Главная инструкция запуска — README. Для автономного Windows x64/CPU комплект содержит `project/`, переносимый Python, локальные wheels, файл зависимостей, скрипты запуска и манифест SHA. В `project/` есть `datasets/` и `weights/`; в новом клоне GitHub их нет.

Распаковать в отдельную папку на любом диске. Из корня комплекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Check.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Web.ps1
```

Скрипты используют свою папку, не имя диска или профиль старого владельца. Новое `.venv` создаётся внутри `project/`; старое виртуальное окружение не копируется. Для Linux/macOS установить Python 3.11 и зависимости по README: Windows wheels/переносимый Python для них не подходят.

Перед редактированием проверьте `Verify-Files.ps1`, после установки — `python -m scripts.check_release`. Первый проверяет весь переданный набор, второй — код и активные артефакты. Проверка SHA не является измерением точности. После собственной работы полный манифест первоначального архива закономерно перестаёт соответствовать изменённым файлам.

Рабочий комплект выбирается единственным `artifacts/mvp/current_release.json`. Не смешивайте головы, справочник, пороги и эталоны разных выпусков. Веса переднего моста включены в артефакты, а не спрятаны в папке старого эксперимента. Для отката сохранять вместе Git-коммит и весь комплект весов/метаданных.

Нужен ответственный за предметную разметку и инженер за выпуск. Исправления пользователей сначала попадают в проверяемую очередь, затем — в групповое обучение кандидата и сравнение. Без сопровождающего оставить рабочую версию замороженной. Текущее приложение от распознавания не обучается.

Дальнейшие задачи, известные ошибки и честные результаты — в MODEL_CARD.md. Этот комплект не включает старый API и его контур обратной связи, историю Git внутри архива и старые дневники экспериментов. Лицензии зависимостей и Python сохраняются.
