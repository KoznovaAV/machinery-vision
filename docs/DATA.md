# Данные

В Git находятся код, небольшой комплект обученных голов и результаты проверки. Фото и большие энкодеры передаются отдельно или загружаются из опубликованных источников. Комплект передачи содержит датасет.

| Путь | Содержание |
|---|---|
| `datasets/manifest.json` | 506 строк train, 9 family-only, основной контроль 158, дополнительные и погодные срезы |
| `datasets/images/` | Изображения по SHA-256, без повторных копий одинаковых байтов |
| `datasets/regions.json` | 597 обучающих областей/эталонов из 333 групп |
| `datasets/region_control.json` | Отдельный контроль настоящих фрагментов машин |
| `datasets/annotations.json` | Проверка областей, разметка деталей, источники и контроль цистерны |
| `datasets/scenes.json` | 20 прежних сцен и ожидаемые ответы для проверки регрессий |
| `datasets/features/` | Совместимые сохранённые признаки и индекс хешей |
| `datasets/summary.json` | Сводный состав набора |

Все пути относительны корню проекта. Число файлов включает исходные кадры и производные кропы: оно не равно числу независимых фото. Источник, группа и смысл метки важнее количества файлов. Метки серии, семейства и точной модели определены в `configs/machinery_taxonomy.json`.

Исходные изображения и производные кропы имеют отдельные хеши. Роль train/test хранится явно; физическое расположение файла не определяет его роль. Изображения одной машины/объявления/съёмки должны оставаться в одном разбиении. Контроль не добавлять в обучение.

При добавлении фото сначала подтвердить реальную технику, модель/семейство, состояние и права на использование; убрать дубли и объединить источники. Уточнение состояния не следует выводить только из мокрой дороги или снега на фоне. Предметная приёмка разметки не завершена.

После ручного изменения манифеста выполнить:

```bash
python -m scripts.build_features
python -m scripts.audit_data
```

Первый скрипт добавляет признаки новых ключей и сохраняет прежние контрольные признаки. Если существующий ключ стал указывать на другое фото, он останавливается. Для полного изменения протокола подготовки данных нужен отдельный эксперимент и новое сравнение; старые признаки нельзя молча считать совместимыми.

Разметки состояния — отдельные строки `condition_rows`. Есть шесть наследуемых групп, где контроль состояния пересекается с обучением распознавания. Этот факт сохранён в метаданных; полностью независимый контроль всей системы ещё нужен.

Исходные фотографии имеют в том числе неподтверждённые права на распространение. Передавайте датасет согласованному разработчику; не публикуйте фото в открытом репозитории без проверки прав.
