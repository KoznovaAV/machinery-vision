# Известные проблемы

## Версии модели и оценка

- API использует v3, а скрипты по умолчанию — v2. Строка `v2-finetune`
  сохранилась в ответах API как прежняя метка версии. Файл модели можно
  однозначно определить по `checkpoint_sha`. См. [реестр весов](../reports/weights_inventory.md).
- Исторические метрики на разных весах и выборках приведены в
  [отчёте от 22 октября](../reports/recheck_2026-10-22.md). Сравнивайте версии
  при одинаковом пороге, чекпоинте и составе выборки.

## Инфраструктура

- **Docker-образ устарел**, нужна пересборка (`docs/DEPLOYMENT.md`).
- **Выбор эпохи для состояния:** `--monitor val_state_acc` отслеживает
  accuracy на указанном валидационном наборе. Для применения на реальных
  кадрах сравнивайте кандидатов по полноте грязи и ложным тревогам отдельно.
- **Интеграционные тесты** для части сценариев API и конвейера данных требуют
  локальные веса и датасеты. В чистом клоне эти сценарии пропускаются.
- **Зависимости не зафиксированы:** `requirements.txt` — нижние границы (`>=`),
  `requirements-docker.txt` — жёсткие пины (`torch==2.1.0`); окружение, на котором
  обучались чекпоинты, не сохранено (подтверждена только версия
  PyTorch Lightning 2.6.5 из метаданных чекпоинтов). Docker-образ в этой проверке
  не собирался; актуальность образа не подтверждена.

## Модель и данные

- **Малый held-out реальной грязи:** `data/real_dirty_val` — 28 фото, ±1 фото
  двигает dirty recall на 0.03–0.04; per-class оценки шумят (`chtz` — 2/3).
  План — собрать 20–30 новых реальных грязных фото (депо / веб), восстановить
  знаменатель val и добавить в train три трудных кейса.
- **Синтетическая грязь ≠ реальная.** На грязи, не похожей на виденную, recall падает.
- **Домен:** преимущественно веб-фото дневной съёмки; ночь, засветка, необычные
  ракурсы, перекрытия ухудшают результат.
- **Нет детектора:** на фото без техники модель вернёт уверенный, но
  бессмысленный класс.
- **Чувствительность к фону:** возможна привязка к цвету техники и типичному окружению семьи.
- **Состояние бинарное и субъективное:** лёгкая пыль может быть распознана как `clean`.
- **Подмодели не различаются:** `mtz_82` и `mtz_1221` слиты в `mtz_belarus`.
- **Шум меток состояния.** Среди промахов v3 есть `clean`-кадры с видимой ржавчиной,
  пылью и мокрой землёй и синтетические `dirty`-кадры, где грязи почти не видно
  (`reports/error_cases.csv`). Потолок метрик состояния ограничен качеством
  меток, а не только моделью.
- **Ложные срабатывания на нейтральные эффекты:** снег на земле, водяные знаки,
  блики, мелкие частицы аугментаций «снег / мыло» приняты за грязь.
- **Реальная грязь только на колёсах, гусеницах и земле** при чистом корпусе
  пропускается (3 промаха v3 на `real_dirty_val`).
- **Версии датасета.** Локальный манифест фиксирует состояние после чистки; `val` и `test`
  синтетики пересозданы 2026-09-11, поэтому старые метрики на них не
  воспроизводятся. Воспроизводимость сплита — `docs/DATA.md` (`--seed 42`), но
  результат зависит от исходного дерева `data/raw`.
- **Пути отсутствуют на машине:** `data.collected_dir` (`data/collected`) и
  `data/collected_dirty` (`docs/RETRAIN.md`, фаза 4c) в рабочем каталоге данных нет.
- **Загрузка чекпоинтов с `weights_only=False`** (`src/models/loader.py`) исполняет
  pickle: чекпоинты из недоверенных источников загружать нельзя.

## Данные на рабочей машине

- **Контроль чистой техники**: в исходном probe из 19 кадров два фото
  `kirovets` побайтово совпали с файлами в `train`. В рабочем probe осталось
  17 фото. Проверка по SHA-256 выявляет точные дубли, близкие кадры требуют
  отдельной проверки.
- `data/vin_lookup.json` — демо-таблица для вкладки VIN в Gradio-демо; источник
  значений не задокументирован, справочником не является.
- Образцы фото ошибок (`output/error_analysis*/…/*.jpg`) в репозиторий не
  включены (≈35 МБ); воспроизводятся `scripts/error_analysis_state.py`.
  Предложенный набор показательных кейсов — `reports/error_cases.csv`.

## Этика

Ошибочная классификация состояния может привести к необоснованному отстранению
техники; решения должны допускать ручную апелляцию. Модель не предназначена для
идентификации людей или чтения номеров.
