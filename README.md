Сервис распознавания сельскохозяйственной техники по фотографии. Конвейер выделяет объекты, определяет тип и семейство, формирует кандидатов модели и оценивает видимые признаки загрязнения и снега. Статус проекта — экспериментальный MVP. Точная модификация автоматически не подтверждается.

## Веб-интерфейс

**[Открыть демо в браузере](https://213efedc5840fb.app.lhr.life/)**

Для проверки демо установка не требуется: откройте ссылку с компьютера или телефона и выберите JPEG, PNG или WebP. Текущая публикация использует временный HTTPS-туннель; при бездействии провайдер может закрыть соединение, а бесплатный домен периодически меняется; адрес и доступность ограничены временем работы сервера и условиями провайдера. Постоянный хостинг не настроен.

Фотографии проходят через [localhost.run](https://localhost.run/docs/forever-free). Конфиденциальные материалы для демо не предназначены. Изображения результата доступны 20 минут; работающий сервер автоматически удаляет временные файлы. Загрузки не используются для обучения. Лимиты: одно фото одновременно, до 8 МБ, 16 мегапикселей и 8192 пикселей по стороне.

Набор тестовых фотографий передаётся отдельно с `index.csv`: в интерфейсе нужно выбирать файл изображения, а не ZIP или таблицу.

Сервис можно установить на собственный компьютер или сервер. Публикация в интернете описана в [инструкции развёртывания](docs/HANDOVER.md#временный-публичный-доступ).

## Установка и запуск

Требования: Python 3.11, Git, Windows/Linux/macOS. Команды выполняются из папки проекта; абсолютные пути не требуются.

```bash
git clone https://github.com/KoznovaAV/machinery-vision.git
cd machinery-vision
python -m venv .venv
```

Активация окружения:

| Система | Команда |
|---|---|
| Windows PowerShell | `.\.venv\Scripts\Activate.ps1` |
| Linux/macOS | `source .venv/bin/activate` |

Установка зависимостей, подготовка весов и запуск:

```bash
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python -m scripts.setup_weights
python -m scripts.check_release
python -m scripts.web
```

Локальный адрес — **http://127.0.0.1:7864/** на том устройстве, где запущен сервер. Для доступа с другого устройства используется публичный URL или адрес сервера. Другой порт: `python -m scripts.web --port 7865`. Остановка — `Ctrl+C`. Первая обработка включает загрузку моделей в память и занимает больше времени.

`setup_weights` загружает около 0,9 ГБ базовых весов; три больших файла проверяются по SHA-256. Обученные классификаторы, пороги и эталоны включены в Git. После подготовки распознавание работает без интернета. Фото для обучения и контроля передаются отдельным комплектом; клонирование репозитория их не скачивает.

Папки по умолчанию: `weights/`, `.cache/`, `runs/`. Кэши можно перенести переменными `TORCH_HOME` и `MACHINERY_VISION_CACHE`. Автономный Windows-комплект описан в [инструкции передачи](docs/HANDOVER.md).

## Поддержка техники и состояния

В справочнике **8 семейств и 10 обучающих меток**. Порог выдачи ответа о семействе настроен для МТЗ-80/82/820, МТЗ-1221, New Holland T5000, CLAAS AXION 800 и ДТ-75. МТЗ-1523, Т-150К и ACROS выдаются кандидатами. T5000 и AXION 800 обозначают серии; МТЗ-80/82/820 часто различаются только на уровне общего семейства.

| Семейство / серия | Верные ответы о семействе / фото | Статус |
|---|---:|---|
| МТЗ-80/82/820 | 58 / 68 | Общее семейство; варианты не подтверждаются |
| МТЗ-1221 | 6 / 12 | Семейство; частые отказы |
| New Holland T5000 | 20 / 26 | Серия; точная модель не подтверждается |
| CLAAS AXION 800 | 12 / 14 | Серия; точная модель не подтверждается |
| ДТ-75 | 7 / 7 | Семейство; контроль очень мал |
| МТЗ-1523 | 0 / 4 | Только кандидат |
| Т-150К | 0 / 6 | Только кандидат |
| ACROS | 0 / 4 | Только кандидат; требуется переразметка |

Числа относятся к расчёту на сохранённых признаках без OCR, а не к точности веб-приложения.

Грязь и снег оцениваются общим модулем. Отдельное качество для каждой пары «семейство × состояние» не измерено. Ответ «чистый», дождь и мокрый корпус отключены. Снег в сцене не доказывает, что корпус машины заснежен. Подробные таблицы: [карточка модели](docs/MODEL_CARD.md).

## Проверенные результаты

Проверка от 16.11.2026:

| Проверка | Результат | Что измеряет |
|---|---|---|
| Классификаторы на сохранённых признаках, без OCR | 158 фото: 103 верных ответа, 3 ошибочных, 52 отказа | Выдачу семейства; без детектора и дополнительных отказов веб-конвейера |
| Зимний срез тем же способом | 12 фото: 4 верных ответа, 3 ошибочных, 5 отказов | Качество остаётся низким |
| Загрязнение | 39 ответов на 63 метки, 1 ошибка | Признаки грязи; без подтверждения чистоты |
| Снег | 8 ответов на 81 метку, 0 ошибок | Наличие снега в сцене/зоне машины |
| Регрессионные сцены | 20 из 20 совпадают с сохранёнными ожиданиями | Стабильность полного конвейера, не независимую точность |

Ранее сохранённый результат 103 верных / 2 ошибочных включал OCR. Он относится к другому протоколу и не используется как текущая воспроизводимая оценка. Показатели выше нельзя называть общей точностью приложения. Контроль использовался при диагностике, предметная приёмка разметки не завершена. Прицепы, ночь, снег и частично видимые машины остаются источниками ошибок.

Выпуск `maintenance7-handover`: первый кандидат МТЗ улучшен с 34/68 до 36/68 на известном контроле без OCR. Ответы о семействе и модуль состояния сохранены. Смешанная метка ACROS больше не предлагается как точная модель 550. [Сравнение экспериментов](evaluation/improvements.json).

## Проверки и обучение

```bash
python -m scripts.check_release
python -m pytest tests -q
```

Для следующих команд необходим отдельный комплект `datasets/`:

```bash
python -m scripts.audit_data
python -m scripts.benchmark
python -m scripts.evaluate
python -m scripts.train --task mtz
python -m scripts.train --task conditions
python -m scripts.train --task families
python -m scripts.train --task regions
```

Обучение сохраняет кандидатов в `runs/training/`. Рабочие артефакты `artifacts/mvp/` не заменяются автоматически. Порядок подготовки данных и допуска кандидата: [данные](docs/DATA.md), [обучение](docs/TRAINING.md).

## Структура

| Папка | Содержание |
|---|---|
| `src/models/` | Детектор, энкодеры, классификаторы, OCR, анализ состояния |
| `src/training/` | Обучение и сравнение кандидатов |
| `src/web/` | Ограничения публичных загрузок и удаление временных файлов |
| `scripts/` | Команды запуска, подготовки весов, проверки и обучения |
| `configs/` | Иерархия типов, семейств и моделей |
| `artifacts/mvp/` | Обученные классификаторы, пороги и эталоны |
| `evaluation/` | Протоколы и результаты проверок |
| `datasets/` | Фото, разметка и признаки; отдельный комплект |
| `weights/` | Базовые веса; загружаются отдельно |
| `runs/` | Результаты распознавания, отчёты и кандидаты |
